# ❄️ Code a Snowman

Welcome to **Code a Snowman** ❄️☃️  
This is a starter (skeleton) project provided for the event.

👉 Participants must **fork this repository** and build their own snowman using creativity and code.

## 🍴 Fork the Starter Code
Click the link below to fork the repository and start building your snowman:

👉 https://github.com/mhd-humraz/snowman/fork

> Make sure you are logged into GitHub before clicking the link.
---

## 🎯 Objective
Start with the given basic snowman structure and enhance it creatively using:
- HTML
- CSS
- (Optional) JavaScript

There are **no fixed limits** on creativity — just build a fun snowman ❄️

---

## 🧊 Starter Code
This repository contains a **basic snowman skeleton**:
- 3 circles (Head, Body, Base)
- Simple layout
- No decorations

Your task is to improve it.

---

## 🧱 What You Can Add
You are free to add:
- Face (eyes, nose, mouth)
- Accessories (hat, scarf, hands)
- Background (sky, snow, ground)
- Animations (CSS or JS)
- Interactions (using JavaScript – optional)

✨ Creativity matters more than complexity.

---

## 📁 Recommended Project Structure
```
code-a-snowman/
│
├── index.html
├── script.js (optional)
└── README.md
```

---

## 📜 Rules
- ✅ Fork the repository (do not commit to main repo)
- ✅ HTML & CSS are mandatory
- ✅ JavaScript is **optional**
- ❌ No external frameworks (React, Bootstrap, etc.)
- ❌ No image assets (draw using code)

---

## 🏆 Evaluation Criteria
- Snowman structure
- Creativity & design
- Clean and readable code
- Extra features / animations

---

## 🚀 How to Participate
1. Fork this repository
2. Clone your fork
3. Build your snowman creatively
4. Commit & push your changes
5. Submit your GitHub repository link

---


## 🎉 Have Fun!
A snowman doesn’t have to be perfect —  
it just has to be **yours** ☃️✨

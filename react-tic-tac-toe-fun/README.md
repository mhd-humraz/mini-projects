# ❌⭕ Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built to demonstrate core programming logic, game flow handling, and clean UI interaction.  
This project is beginner-friendly and focuses on clarity, logic, and user experience.

---

## 🎮 Features

- Two-player gameplay (Player X vs Player O)
- Interactive game board
- Automatic win detection
- Draw detection
- Game reset functionality
- Clean and minimal design

## 🚀 How to Run the Project

### Option 1: Run Locally
1. Clone the repository:
   ```bash
    git clone https://github.com/mhd-humraz/react-tic-tac-toe-fun.git
   ```
Navigate to the project directory:
```
cd tic-tac-toe-react
```

Install dependencies:
```
npm install
```

Start the development server:
```
npm run dev
```

(or npm start if using CRA)

Open your browser and visit:
```
http://localhost:5173
```
## 🧠 Game Rules

Player X always starts first

Players alternate turns

First player to align three marks (row, column, or diagonal) wins

If all squares are filled without a winner, the game ends in a draw

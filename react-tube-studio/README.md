# 🎥 ViewTube – YouTube Clone

ViewTube is a YouTube clone built using React.js, designed to replicate the core UI and functionality of YouTube.
This project is created for learning purposes, focusing on React components, API integration, and modern UI design.

## 🚀 Features

📺 Browse and watch videos

🔍 Search videos

📂 Category-based video listing

📱 Fully responsive design

🎨 Modern UI inspired by YouTube

⚛️ Built with React & Material UI

---

## 🛠️ Tech Stack
```
React.js

Material UI (MUI)

RapidAPI / YouTube API (if used)

CSS / Styled Components

Vite / CRA (based on your setup)
```

📦 Installation & Setup

Clone the repository
```
git clone https://github.com/mhd-humraz/react-tube-studio.git 
```

Navigate to the project folder
```
cd viewtube
```

Install dependencies
```
npm install
```

Start the development server
```
npm run dev
```

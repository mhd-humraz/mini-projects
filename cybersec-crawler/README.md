# CSRF Scanner Project

This project demonstrates the identification and exploitation of **Cross-Site Request Forgery (CSRF)** vulnerabilities in web applications.  
It includes research on CSRF protections, a Python-based crawler to detect missing CSRF tokens, and an HTML Proof of Concept (PoC) that demonstrates a CSRF attack.

---

## 📌 What is CSRF?

Cross-Site Request Forgery (CSRF) is a web security vulnerability that allows an attacker to trick an authenticated user into submitting a malicious request to a trusted web application.  
Because browsers automatically include session cookies, the server may treat the request as legitimate.

---

## 🔐 Why CSRF Protection is Important

Without proper CSRF protection, attackers can perform unauthorized actions such as:
- Changing user account details
- Triggering sensitive state-changing requests
- Performing actions without the user’s consent

To prevent this, applications typically use **CSRF tokens**, **SameSite cookies**, or **origin validation**.

## 🕷️ CSRF Vulnerability Crawler

### How the Crawler Works
1. Sends an HTTP request to the target URL
2. Parses the HTML response
3. Extracts all `<form>` elements
4. Checks each form for CSRF tokens in input fields
5. Flags forms missing CSRF protection
6. Saves the results to `report.txt`

---

## ▶️ How to Run the Crawler

### Requirements
- Python 3
- `requests`
- `beautifulsoup4`

Install dependencies:
```
 pip install requests beautifulsoup4
```

Run the crawler:
```
 python3 crawler.py
```
Enter the target URL when prompted:
```
Enter target URL: http://testphp.vulnweb.com
```
After execution, the scan results will be saved automatically to report.txt.

🧪 CSRF Proof of Concept (PoC)

The poc.html file demonstrates a CSRF attack scenario where:

The victim is already logged into the target application

The application does not validate CSRF tokens

A malicious HTML page auto-submits a forged request

Opening this file in a browser can trigger an unauthorized action if the target is vulnerable.

📄 Report

The report.txt file contains details of detected vulnerable forms, including:

Form number

Action URL

HTTP method

CSRF token presence status

This file serves as evidence of the identified vulnerability.
